# Copilot Instructions for news-cluster-agent

- This agent receives analyzed news articles (from the news-analyzer-agent) and clusters them by topic/story using AI.
- Each article is assigned a group story title (cluster title) generated by a summarization model.
- The cluster title is written back to the database record for each article.
- The agent expects a PostgreSQL database with a `news_articles` table containing at least: `id`, `title`, `content`, and `cluster_title` columns.
- Configure database connection via environment variables: `NEWS_DB_HOST`, `NEWS_DB_PORT`, `NEWS_DB_NAME`, `NEWS_DB_USER`, `NEWS_DB_PASS`.
- To add or change clustering logic, edit `main.py`.
- To update dependencies, edit `requirements.txt` and run `pip install -r requirements.txt` in the `.venv`.
